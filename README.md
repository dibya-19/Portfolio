## Running locally

No build tools required — just open the file in a browser:

```bash
git clone https://github.com/dibyalochan/portfolio.git
cd portfolio
open index.html   # or double-click the file
```

## Deploying with GitHub Pages

1. Push this repo to GitHub (make sure the site file is named `index.html`).
2. Go to **Settings → Pages** in the repo.
3. Under **Source**, select the `main` branch and `/ (root)` folder, then **Save**.
4. GitHub will publish the site at `https://<username>.github.io/<repo-name>/` within a minute or two.
5. Add that link to your LinkedIn profile's **Featured** section or website field.
